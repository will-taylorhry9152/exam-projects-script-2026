## What This Collection Contains

Exam Projects is a small PHP-based training repository intended for exam study and practical coding work. Each project concentrates on a limited problem, allowing you to inspect how program structure, changing state, and user-controlled operations can be implemented.

The examples include an ATM, digital safe, vending machine, and calculator. Together, they cover object-oriented programming, session use, balance checks, PIN authentication, stock control, and calculating change from coins. They can be used for revision, guided study, or independent implementation exercises.
